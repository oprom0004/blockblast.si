Explore the tree-search permutations, survival heuristics, and probabilistic combo models that power BlockBlast.si.

PERMUTATION LOGIC

1. The 6-Way Factorial Permutation Tree

In standard Block Blast, players are handed 3 pieces at a time. The order in which pieces are placed drastically alters line-clearing cascades:

Permutations = 3! = 3 × 2 × 1 = 6 Distinct Branches
[A ➔ B ➔ C], [A ➔ C ➔ B], [B ➔ A ➔ C], [B ➔ C ➔ A], [C ➔ A ➔ B], [C ➔ B ➔ A]

For each permutation, our client-side solver computes every valid coordinate (0 ≤ row ≤ 7, 0 ≤ col ≤ 7), checking board intersections and executing simultaneous row and column removals in real time.

EVALUATION FUNCTION

2. Multi-Factor Survival Evaluation

A move that clears 2 lines immediately is NOT always optimal if it leaves the remaining board fragmented with isolated 1x1 holes. Our evaluation function balances 4 core vectors:

  • Line Clear Score: Immediate points earned from horizontal and vertical line eliminations.
  • 3×3 Giant Box Reserve (+400 pts): Heavily rewards board states that leave a clear 3×3 sector open for large square block spawns.
  • Isolated Hole Penalty (-50 pts / hole): Punishes empty single squares surrounded on 3 or 4 sides by filled blocks that cannot be cleared without specific 1x1 drops.
  • Empty Board Density (+15 pts / free cell): Maintains maximal open surface area across the 8×8 grid.
